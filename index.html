核心功能与技术亮点

全场景经典右键菜单治理

一站式管理文件、文件夹、目录背景、桌面背景、驱动器、回收站及所有对象的 Shell Verbs 与 ShellEx ContextMenuHandlers，一键启用或禁用，毫秒级生效。

专用菜单与扩展定制

完整支持“发送到 (SendTo)”、“打开方式 (OpenWith)”、“新建 (ShellNew)”、“Win+X 快捷菜单”定制，以及基于文件扩展名（File Types）的菜单项治理。

进程外 COM 沙箱分析器

在独立的 64 位与 32 位双架构原生沙箱进程 (Prober.exe) 中模拟真实文件右键，安全枚举完整菜单树与图标，彻底隔离第三方恶意扩展崩溃对主程序的影响。

状态基线与防篡改审批

自动建立注册表基线快照。当第三方软件在后台静默注入或修改右键菜单时，立即标记并送入审批队列，防止桌面右键被恶意绑定。

安全备份与一键恢复

所有禁用、重命名、参数调整及删除操作均具备本地增量快照保护，支持随时一键完全回滚，确保系统注册表万无一失。

轻量纯净与现代化体验

纯原生 C++ 构建，无繁重第三方框架依赖。完美自适应 Windows 亮暗主题与高分屏 DPI，支持中英双语界面一键平滑切换。

隐私政策 / Privacy Policy

生效日期 / Effective Date: 2026-11-14

应用名称 / Application: 右键菜单管理器 / Context Menu Manager Neo (CMMN)

中文概要

100% 本地运行，零数据收集与上传：本软件是一款纯本地 Windows 桌面系统工具。不包含任何统计分析 SDK（Analytics）、崩溃遥测上报组件或广告追踪器；程序不发起任何互联网请求，在 Microsoft Store 清单中亦未声明 internetClient 网络权限。

本地数据存储：所有界面偏好、右键菜单状态基线及操作备份均严格保存在您的本地设备中（%LocalAppData%\CMMN\data 或便携版的 data\ 目录），绝不会离开您的电脑。

系统权限：本软件声明 runFullTrust、allowElevation 与 unvirtualizedResources 仅用于读写真实的 Windows 资源管理器 Shell 注册表项并启动独立的 COM 沙箱探测子进程。

English Summary

100% Offline with Zero Telemetry: Context Menu Manager Neo (CMMN) is a standalone Windows desktop utility. It contains zero analytics SDKs, zero telemetry uploaders, and zero advertisements. It makes no internet connections and does not declare the internetClient capability.

Local Data Storage: All settings, baselines, and backups reside strictly on your local disk (under %LocalAppData%\CMMN\data or the portable data\ directory) and never leave your machine.

Permissions Disclosure: Declarations of runFullTrust, allowElevation, and unvirtualizedResources are strictly required to read/modify real Explorer context menu registry keys and spawn the isolated prober process.
